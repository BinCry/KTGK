# Ban Học Tập Khoa CNPM – UIT

Trang web giới thiệu Ban Học Tập Khoa Công nghệ Phần mềm, Trường Đại học Công nghệ Thông tin – ĐHQG-HCM. Website cung cấp tài nguyên học tập, thông tin hoạt động và kênh liên hệ cho sinh viên.

## Công nghệ sử dụng

- **HTML5** — cấu trúc nội dung và khả năng truy cập.
- **CSS3** — giao diện, bố cục responsive và hiệu ứng hiển thị.
- **JavaScript (ES5)** — menu điều hướng, cập nhật trạng thái mục đang xem, nút về đầu trang và kiểm tra biểu mẫu.

## Chạy dự án

1. Tải hoặc clone repository.
2. Mở `index.html` bằng trình duyệt.

Không cần cài đặt thêm thư viện hoặc công cụ build.

## Cấu trúc thư mục

```text
website/
├── index.html
├── style.css
├── script.js
└── images/
```
